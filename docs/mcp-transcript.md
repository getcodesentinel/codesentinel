# CodeSentinel MCP transcript

Captured against this repository after `pnpm build`, on the `feat/mcp-server` branch.
One JSON-RPC message per line on stdout; every log line on stderr. The `sleep` keeps stdin open
until the slower `get_reading_path` response is written, because the MCP stdio binding aborts
in-flight requests when stdin reaches end of file.
